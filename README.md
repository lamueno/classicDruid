## 简介

本项目是《魔兽世界》经典怀旧服（60级香草时代）**P5阶段 (安其拉神庙)** 熊T（守护德鲁伊坦克）的装备评分模型 **v4.4** 版本，最后更新于 **2020年8月18日**。

该模型最初通过 **石墨文档** 发布，旨在为香草时代后期（特别是TAQ和NAXX阶段）的熊T玩家提供一个量化工具，用于评估和比较装备，核心目标是在复杂的生存（EHP - 有效生命）和仇恨（TPS - 每秒仇恨）需求之间找到平衡。

近期收到一位水友的私信，希望能重新获取此模型。为了响应社区需求并方便更多玩家，我决定将这份文档整理并 **开源** 到 GitHub，供大家参考、使用和讨论。

## 背景

在香草时代，尤其是像纳克萨玛斯这样的高难度副本中，熊T的装备选择极具挑战性。玩家需要在有限但多样化的装备池中，精确权衡生存属性（耐力、护甲、敏捷、防御技能、闪避等）和仇恨属性（力量、敏捷、命中、暴击、攻击强度、武器特效等）。此模型试图：

1. **量化属性价值**：根据数学模型为各项属性赋予相对分数。
2. **平衡生存与仇恨**：引入“仇恨-生存权重” (`p`) 的概念，允许用户根据自身定位（如主坦、副坦）或特定Boss战调整评分侧重。
3. **考虑尖峰伤害**：v4.2 版本后开始考虑“尖峰伤害”问题，更重视能平稳血线的属性。
4. **提供决策支持**：通过分数直观比较装备，辅助构建最佳配装 (BiS) 列表。

## 模型核心与方法论 (v4.4)

* **核心指标**: 模型主要围绕提升 **有效生命 (EHP)** 和 **每秒仇恨 (TPS)** 进行量化。
* **仇恨-生存权重 (`p`)**: 这是模型的关键可调参数。它代表了多少 EHP 的价值等同于 1% TPS 的提升。
  * **`p=1`**: 认为 1% EHP 提升 和 1% TPS 提升具有同等价值 (相对均衡或偏仇恨)。
  * **`p=5`**: 认为 5% EHP 提升 才相当于 1% TPS 提升 (更侧重生存，适用于生存压力大的场合或“乌龟”玩法)。
  * 模型可能提供基于不同 `p` 值的多个评分结果（如：均衡分、乌龟分、疯狗分），以适应不同场景和玩家偏好。
* **尖峰伤害考量**: 调整了部分属性（如耐力、护甲）的权重，以反映其在应对突然高额伤害（尖峰伤害）时的重要性。
* **评分计算**: 基于复杂的公式（详见模型文件），将装备的各项属性、套装奖励、甚至附魔和宝石（如果适用）转换为可比较的分数。
* **基准环境 (v4.4 参考)**: 模型评分可能基于特定的游戏环境假设，例如：
  * 天赋: 标准熊T天赋 (如 11/33/7)
  * 场景: TAQ/NAXX Boss战
  * 团队Buffs: 赞扎之魂、厄运Buff、风歌花、坚韧祷言、血之契印、野性赐福等常见世界和团队Buff。
  * 消耗品: 猫鼬、魂能之力、强效石盾、嫩狼肉排、戈多克绿酒等。
* **分数可加性**: 同一部位的不同装备分数可以直接比较。附魔、Buff和药剂的分数也基于其对EHP/TPS的贡献进行计算，理论上可以与装备分数叠加衡量总提升，但主要用于同类比较。

具体的评分细则、属性权重、计算公式以及各装备的详细评分，请查阅仓库内的核心模型文件：

## 如何使用

1. **克隆或下载** 本仓库到你的本地计算机。
   ```bash
   git clone https://github.com/lamueno/classicDruid.git
   ```

   或者直接点击页面上的 "Code" -> "Download ZIP"。
2. **找到并打开** 核心模型文件 ([`当前阶段(P5)熊T装备评分.xlsx`](ranking/当前阶段(P5)熊T装备评分.xlsx))。这是一个位于 `ranking` 目录下的电子表格文件，需要 Microsoft Excel, Google Sheets, LibreOffice Calc 或类似软件打开。
3. **查阅模型**: 理解不同权重配置下的评分（均衡、乌龟、疯狗等），查看各装备的分数。
4. **应用与比较**: 使用分数来评估你持有或计划获取的装备。根据你的团队需求和个人打法，选择合适的权重标准（`p`值）进行参考。
5. **注意**: 模型是基于特定假设和理论构建的，实际效果可能受战斗复杂度、团队配置、个人操作等多种因素影响。请结合自身经验判断。
